# Getting Started

## Prerequisites
- Ensure you have the necessary software installed: Node.js, npm, etc.

## Steps
1. Clone the repository: `git clone <repository_url>`.
2. Navigate to the directory: `cd <directory>`.
3. Install dependencies: `npm install`.

### What You'll Learn
In this guide, you will learn how to set up the New Docs Workspace.
